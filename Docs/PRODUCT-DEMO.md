# XShot 产品演示

版本：0.2.0；更新日期：2026-10-25。本文说明当前实现、交互参考及验证边界；真实安装与桌面操作的验证结果另见 [VERIFICATION.md](../VERIFICATION.md)。

## 功能与交互参考

参考范围是公开可观察的功能和交互。XShot 使用独立编写的 Swift/AppKit、ScreenCaptureKit、AVFoundation、Core Image 和 HTML/JavaScript 实现，没有复制这些产品的代码、图标、界面素材或品牌内容。

| 成熟产品与一手资料 | 可借鉴的交互 | XShot 当前采用的做法 |
| --- | --- | --- |
| [Screen Studio 官网](https://screen.studio/) | 根据操作自动安排缩放，并允许录制后调整焦点和缩放片段；动画由工具完成，用户主要决定展示哪里。 | 根据点击生成默认缩放片段；用户可调整起止时间、倍数和焦点，或关闭片段及整个自动聚焦。 |
| [Cap 官网](https://cap.so/) | Studio 工作流先本地录制，再进入预览和编辑；背景、留白、阴影、光标和缩放服务于画面阅读。 | 停止录制后进入同一编辑器；保留原片及输入元数据，视频预览和导出共享渲染器，统一圆角、浅阴影和鼠标效果。 |
| [Arcade 交互演示产品页](https://www.arcade.software/product/interactive-demo) | 将操作整理为可点击步骤，热点和说明引导观看；分支让观众选择路径。 | 自动生成步骤截图和热点，提供缩略图列表、标题与说明编辑、热点拖动和目标步骤选择。 |

## 录制一次，制作两种演示

1. 按 **⌥R（Option + R）**，或从主窗口/菜单进入“产品演示”，选择屏幕、独立窗口或单屏内区域，确认静态预览并填写项目名称。
2. 点击“开始录制”，准备页立即隐藏，所选范围显示边框及独立倒计时；倒计时可选无、3 秒或 5 秒。控制器显示有效时长、步骤数、暂停/继续、重新录制和完成；XShot 自身窗口从采集画面排除。
3. 在其他应用中正常演示。原始视频不含光标和音频；鼠标位置、点击时间及坐标另存，供编辑阶段绘制光标和安排缩放。当前不采集键盘输入。
4. **⌥P** 或控制器可暂停/继续，暂停期间的时间、画面与操作不进入结果。重录会先保存上一条独立项目，再重新倒计时。点击“完成”或再按 **⌥R**，保存本地项目并打开编辑器。选择“演示视频”或“交互步骤”，编辑后分别导出 MP4 或 HTML。

当前一次录制单显示器整屏、单个独立窗口或显示器内的框选区域，H.264 原片宽度最高 1920 像素、目标最高 60 fps，鼠标位置也以 60 Hz 采样，按范围比例保存为偶数像素尺寸。窗口移动时鼠标坐标跟随，调整窗口尺寸时保持初始编码画布。不支持同时录制多个显示器。启动需收到首个有效画面，8 秒无画面则报错。

## 演示视频

拖动播放条，在右侧“保留范围”按当前播放位置设置入点/出点；可恢复整段及撤销/重做。预览与 MP4 导出使用同一范围，鼠标、点击和缩放保持原片时间。裁剪只保存编辑参数，不改写原片，交互步骤不受影响。

自动聚焦会将时间相近、位置邻近的点击安排在同一缩放片段中，减少来回拉近拉远；每次真实点击仍分别保留。重叠片段组成连续镜头，利用录后已知的轨迹提前约 380 毫秒安排取景，让普通操作在点击时已进入镜头。镜头进出使用约 0.72 秒缓动，焦点转换仍使用约 0.9 秒、速度与加速度连续的路径。极快连续点击远处目标时，会平滑扩大视野，保留操作与短暂响应，随后恢复聚焦。可见光标按事件时间插值，点击本身作为精确位置锚点。

左侧列出可编辑的缩放片段，右侧可调整开始、结束、倍数和启用状态。“在画面中定位”会暂停预览，临时显示同一帧的全景；点击画面重新指定焦点，随后恢复缩放预览。坐标会扣除预览的等比留白和视频修饰边距，镜头裁切限制在原画面内。

“自动聚焦”“显示鼠标”“点击提示”可分别关闭。画面默认保留少量留白、圆角和浅阴影，点击用短暂圆圈提示。关闭自动聚焦后保持 1x 全景。

预览通过 AVPlayerItemVideoOutput 解码原片，并以显示器同步的 60 Hz 时钟将 Core Image 结果直接提交到 Metal 显示层；解码画面与效果使用同一预计显示时间。静态背景和阴影保留在 GPU，预览按可见像素尺寸渲染。导出通过 AVAssetReader/AVAssetWriter 顺序读取和编码；两条路径使用同一条可随机定位的镜头路径和同一个合成器。MP4 使用 H.264，保持项目原片尺寸，以固定 60 fps 输出。已有 30 fps 项目的镜头与光标也以 60 fps 重新合成，源画面保留原有采样率。

ScreenCaptureKit 在静止屏幕上可能仅提供少量变化帧，因此原片可以是可变帧率（VFR）。导出只保留当前与下一张源图，在每个目标帧时间复用相应原画并重新计算效果；预览播放时也会在没有新源图的间隔继续重绘。这样静止画面中的鼠标、点击圈和镜头动画仍连续，不受原片帧数限制。定位播放时间时使用该时刻对应的源图，效果按目标时间计算。

导出在后台进行并提供进度和取消；先写独立临时文件，成功后才替换目标，取消保留原片、项目及已有目标文件。

## 交互步骤

每次有效点击使用输入事件之前最近的一帧生成步骤，热点标示观众应点击的位置，避免把点击后的结果画面误当成操作入口；停止后另加一张最终结果图。快速连续点击、同位置双击和三击均保留事件时间与位置。自动步骤最多约 200 张（含结果图），过快操作导致写图队列饱和时会提示；这些图片预算只限制步骤截图，视频和全部点击轨迹仍保留，用户可补充步骤。

编辑器支持：

- 通过缩略图选择步骤，修改演示名称、步骤标题和说明。
- 点击或拖动热点调整位置，移除热点，选择点击后的目标步骤形成分支。
- 添加截图步骤、上移下移、删除，以及撤销和重做。
- 在“编辑”和“预览”间切换；预览按实际路径前进，返回会沿观看历史回退，结束后可以重新开始。

自动标题当前为“步骤 1”“步骤 2”等，说明为通用提示；没有理解按钮语义或自动生成业务说明。发布前应将这些文字改为该操作的具体目的和预期结果。

导出的 HTML 内嵌步骤图片、文字和播放器，无需服务器即可在浏览器离线打开。导出物用于播放；继续编辑应重开 `.xshotdemo` 项目。它不会连接、操作或保存被展示产品的数据，热点仅改变演示的当前步骤。

## 本地项目与边界

项目默认位于 `~/Movies/XShot/`，每次录制保存一个 `.xshotdemo` 包，包含：

```text
演示 日期-标识.xshotdemo/
  recording.mov       原始无音频、无光标视频
  project.json        鼠标轨迹、点击、缩放、步骤文字及跳转关系
  steps/             步骤 PNG
```

从准备页“最近项目”、“打开项目…”、“打开演示项目…”或 **⌘⇧O** 可以重开，编辑自动保存到项目。原片与编辑参数分开保存，调整步骤、裁剪和缩放无需重新录制。

当前尚未实现录音、系统音频、摄像头、云分享、AI 生成步骤说明，以及敏感信息自动遮挡或打码。这里的交互演示是截图与热点组成的离线播放，不是浏览器 DOM 克隆，也不是叠加在真实网页中的实时操作引导。
