# 标注交互验收 · 2026-10-27

影响范围：截图框选浮层与标注编辑器共用的画布、工具栏及快捷键。

交互参考 [Shottr 官方入门说明](https://shottr.cc/kb/startguide) 中的可重选、移动、缩放和随所选对象切换属性的做法。文字按实际画面大小提供可读默认值；马赛克按本次需求采用可连续涂抹的圆形笔刷。

## 本轮行为

| 功能 | 修复后的操作 | 验证 |
| --- | --- | --- |
| 选择 V | 点击任意标注选中，边框与手柄可见；拖动移动，空白处取消选择 | 五种对象逐项通过；安装版实测文字、矩形、箭头、画笔 |
| 矩形 R | 拖动绘制，直接拖已显示的角手柄改宽高；选中后改色、线宽 | 像素、历史、按钮及安装版直接拖手柄通过 |
| 箭头 A | 拖动绘制，端点手柄调整方向和长度，整体可移动 | 端点缩放、整体位移、安装版实测通过 |
| 画笔 P | 连续自由笔划、圆端点、单击画点；松开后继续下一笔 | 连接路径、点涂、连续操作、选择及缩放通过 |
| 文字 T | 默认约 28 点可见大小，补偿 Retina 与画布缩放；手选字号后保持用户数值 | 25/50/100/200% 画布检查；安装版 100% 时 28 px、80% 时 35 px 通过 |
| 文字编辑 | 回车换行，⌘回车完成，双击重编；手柄缩放、颜色、字号和文字撤销 | 专项及原生菜单响应链通过；角手柄附近双击也能编辑 |
| 马赛克 M | 沿笔刷路径涂抹、圆头、单击点涂、独立直径；松开后继续涂抹 | 路径内像素改变、路径外像素原样、快速笔划连接与两笔连续涂抹通过 |
| 马赛克内容 | 对当前画面取样，包含刚添加的文字和其他标注 | 安装版在纯白源图上新建红色文字后，涂抹得到红色像素块，未涂抹第三行保留 |
| 属性控件 | 选中文字显示字号，选中马赛克显示笔刷大小，其他对象显示线宽；马赛克禁用颜色 | 六个原生工具按钮、选择对象后同步、最小窗口布局通过 |
| 微调、删除、清空 | 方向键 1 原图像素，Shift 10；Delete 删除所选；清空可撤销 | 五种对象逐项通过 |
| 历史与中断 | 每次拖动、缩放、笔划只记一条状态；Esc 取消拖动；原生菜单撤销保护进行中的笔划与拖动 | 像素级撤销/重做、未提交笔划与原生 undo: 入口通过 |
| 输出 | 复制、PNG 保存和贴图使用相同渲染，不输出选中边框和手柄 | 独立剪贴板、图像渲染、美化回归及原生 PNG 保存通过 |

框选中没有标注时，V 仍允许调整截图范围；存在标注时，V 选择标注，截图范围保持固定。清空后可再次调整截图范围。

## 检查入口

- `scripts/check-annotation-interactions.sh`：新增完整工具矩阵及像素检查。
- `scripts/check-text-annotations.sh`：多行、长行、输入法组合态、光标、编辑与渲染一致性。
- `scripts/check-selection-annotations.sh`：真实浮层视图命中、选择保护、字号与调色、直接复制/保存、编辑器交接。
- `scripts/check-keyboard-shortcuts.sh`：工具与上下文尺寸、系统菜单与文本响应链。
- `scripts/check-clipboard.sh`、`scripts/check-settings.sh`、`scripts/check-beautification.sh`、`scripts/check-window-selection.sh`、`scripts/check-rendering.sh`：相关回归。

以上九组检查均通过。合成图检查使用固定原图像素，避免有无真实 Retina 显示器改变源图尺寸。输入法组合态通过 NSTextView marked-text API 模拟；没有把它写成物理输入法候选栏验收。

## 安装版实测与产物

已在 `/Applications/XShot.app` 上用本地 PNG 完成真实按钮、拖动、缩放、工具切换、马赛克连续涂抹、选择重编、撤销重做与系统保存面板操作。780 点宽窗口六个工具、参数、历史及输出按钮均可见。80% 画布新文字默认字号自动补偿为 35 px，保持约 28 点的可见大小；1000×600 源图在 94% 画布显示时默认 30 px。

- `artifacts/annotation-interaction-checks/native-all-tools.png`：五种标注的实际 PNG 导出。
- `artifacts/annotation-interaction-checks/final-verification.png`：直接拖矩形手柄、连续两笔马赛克覆盖新文字的实际 PNG。
- `artifacts/annotation-interaction-checks/mosaic-brush.png`：非矩形笔刷路径的像素检查样本。
- `artifacts/annotation-tools-install-20261027/installation.json`：安装文件哈希；原始安装版与中间版分别保存在同目录 Previous、Intermediate。

更新后系统提示需要重新关联屏幕录制权限，本轮未修改系统隐私授权。实际屏幕采集后的浮层未计入实机验收，其工具行为由共用画布和隐藏浮层检查覆盖。
