# XShot 标志概念

后续定稿：用户已选择 A「开角」。配色、应用图标和完整资源已生成于 `Final/`，当前指南见 `Final/GUIDE.md`。以下内容保留概念阶段的探索与验证过程。

## 设计假设

XShot 是面向日常办公、写作和开发者的原生 macOS 截图工具。标志首先用于菜单栏、Dock 和应用窗口。基于用户“简约好看”的要求，采用克制、准确、轻巧、可信四个关键词；先以黑白轮廓判断，不靠渐变、阴影和装饰补足识别。

约束：名称写作 XShot；独立绘制，不使用 iShot 图形；16、32、64 px 可辨；符号必须支持单色、透明背景和反白。当前交付三种可选概念，尚未定稿或安装。

## 研究与策略

研究了技能库的 design-creative 分类（35 个标志）及 frame / letterform / negative-space 分类；阅读 Pagekit、Precursor、Zendesk、Framer 的几何构造，仅研究方法，不描摹。此类软件常见的相机、剪刀、四角框、彩色渐变和未经改造的 X 容易混同，本轮避免直接照搬。

词图：X → 相交、切口；Shot → 一瞬、截取；标注 → 精确、边界；贴图 → 抬起、悬浮；美化 → 留白、秩序。优先探索“打开的边界”“交点中的窗口”和“由角折成的 S”。

## 构造

A：256 画布、32 单位外留白；28 单位框体；外圆角 24；右上角以 45° 分离成一块独立的角，边框本身作为标识。

B：256 画布；四条 45° 对角笔画组成宽 X；中心用 44 单位的真实透明方孔指向“截出一个窗口”。与普通 X 的差异在中心结构。

C：256 画布；32 单位主干和 45° 折角；由上、下两个有方向的折角连成 S。方向与 A、B 的中心对称区别明显，也保留 Shot 的首字母联想。

文字仅作为概念卡说明；本轮 SVG 符号没有字体依赖。不是商标查重或注册审查。

- 第二轮渲染后，A 内角增添 8 单位圆角，B 方孔由 40 放宽到 44，C 两端各缩短 8 单位以平衡视觉重量。
- 三轮源码均保留；最终 `a-open-corner.svg`、`b-cross-window.svg`、`c-folded-s.svg` 与 v3 一致。
- 最终符号均以技能 `svg_audit.py` 检查：无活文字、位图、滤镜、渐变或描边依赖；黑色单色、透明真孔洞；各得到 100/100 的结构启发式分数。这个分数不是美学或商标保证。
- 已实际查看 `artifacts/logo-concepts/concepts.png` 和 `verification.png`：64、32、16 px 仍保留主特征；白底黑标、黑底白标、镜像及 180° 旋转均可读，没有看到意外碎片、接缝和不当含义。反白在小尺寸略显厚，正式版本可对反白几何再做 2–3% 光学校正。
- `pass-1.html` 含 Pagekit、Precursor、Framer 作为等高同行参照，已生成；最终仍以自己的符号独立绘制。未做外部商标数据库或反向图片检索。

## 建议

推荐 A：功能关联最直接，圆角和留白更贴近原生 Mac 工具，唯一的断角也适合做短动画。风险是易先读成“导出”；可通过 XShot 名称建立含义。

B 的 X 关联最强、16 px 的实体轮廓最饱满，风险是字母 X 自身品牌联想较多。C 更有速度和操作感，风险是 S 与完整名称的关联较间接。

当前为概念检查点。按 logo-design 技能要求，先展示三案，由用户选择后再制作配色、正式反白、字标锁定、macOS ICNS 与应用内替换；尚未做应用图标或修改应用资源。
